# Shyam — श्याम

Concept build for **Shyam**, an all-black clothing house named after Krishna,
releasing one drop per new moon (*amavasya*).

| Page | What it is |
| --- | --- |
| `index.html` | Storefront — live countdown, Drop 001 line, quick view, bag, drop calendar |
| `logo.html` | Identity development record — 91 marks across 7 phases, and the resolved mark |
| `brand.html` | Brand book — mark spec, drop clock, the five blacks, typography, voice, applications |
| `plan.html` | Business plan — market, SKU-level unit economics, 3-year model, ops, capital, risk |

**The mark:** a solid disc cut once at twelve. Slot width 5% of the diameter,
running exactly to the centre, flat ends. Under 20 px the slot opens to 6.5% —
the only exception in the system. Rotated 30° per drop, it becomes the calendar.

Product imagery is layered vector, not photography. All figures are indicative
planning numbers, not audited accounts.

Static site — no build step. Open `index.html`, or serve the folder.
